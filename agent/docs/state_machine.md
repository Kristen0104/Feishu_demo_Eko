**更新日期**: 2026-04-24

## 状态定义

```
┌─────────────────────────────────────────────────────────────────┐
│ IDLE（空闲）                                                     │
│ - 等待用户在飞书群 @Eko + 一句指令触发任务                        │
│ - 初始状态 / 任务完成后回到此状态                                │
└────────────────────┬────────────────────────────────────────────┘
                     │ 用户在飞书群 @Eko + 一句指令
                     ▼
┌─────────────────────────────────────────────────────────────────┐
│ ANALYZING（意图分析中）                                         │
│ - 调用意图分类 Prompt                                             │
│ - 识别为 CHAT/DOC/PPT/UNCERTAIN                                │
│ - 发送飞书交互卡片，显示"分析中"状态                             │
└────────────────────┬────────────────────────────────────────────┘
                     │
      ┌──────────────┼──────────────┐
      ▼              ▼              ▼
┌───────────┐ ┌─────────────┐ ┌─────────────────┐
│ CHAT      │ │ CLARIFYING  │ │ DOC/PPT（创作） │
└─────┬─────┘ │（追问中）   │ └──────────┬──────┘
      │       └──────┬──────┘            │
      │              │                   ▼
      │              │      ┌─────────────────────────────────┐
      │              │      │ FETCHING_SOURCES（获取三源中） │
      │              │      │ - 通过飞书 API 获取群聊上下文  │
      │              │      │ - 通过飞书 API 获取 Bitable    │
      │              │      │ - 通过飞书 API 检索知识库      │
      │              │      │ - 三类信息均可为空白          │
      │              │      └──────────┬──────────────────────┘
      │              │                 │
      │              │                 ▼
      │              │      ┌───────────────────────────────┐
      │              │      │ GENERATING（内容生成中）      │
      │              │      │ - 调用 Word/PPT Prompt       │
      │              │      │ - 流式输出内容                │
      │              │      │ - 更新飞书卡片进度            │
      │              │      │ - WebSocket 广播状态到工作台 │
      │              │      └──────────┬────────────────────┘
      │              │                 │
      │              │                 ▼
      │              │      ┌───────────────────────────────┐
      │              │      │ SYNCING（同步与回流中）       │
      │              │      │ - 保存到数据库                │
      │              │      │ - 回流到 RAG 知识库          │
      │              │      └──────────┬────────────────────┘
      │              │                 │
      └──────────────┴────────┬────────┘
                              ▼
                ┌─────────────────────────────────┐
                │ COMPLETED（已完成）              │
                │ - 更新飞书卡片为"已完成"状态    │
                │ - 等待用户点击"确认保存"      │
                │ - 用户确认后，归档到 Bitable   │
                │ - 回到 IDLE 状态               │
                └─────────────────────────────────┘
```

## 状态详情

### 1. IDLE（空闲）

**入口条件**：
- 系统初始化完成
- 上一个任务完成

**行为**：
- 等待飞书群聊 @Eko + 一句指令
- 清理临时状态

**退出条件**：
- 收到用户 @Eko + 一句指令触发 → 进入 ANALYZING

---

### 2. ANALYZING（意图分析中）

**入口条件**：
- 从 IDLE 收到用户 @Eko + 一句指令

**行为**：
- 调用 classify_intent Function Calling
- 获取最近对话上下文
- 分析意图
- 发送飞书交互卡片，显示"分析中"状态

**事件发布**：

```json
{
  "type": "INTENT_RECOGNIZED",
  "payload": {
    "intent": "CHAT/DOC/PPT",
    "confidence": 0.95,
    "workbench_url": "https://..."
  }
}
```

**退出条件**：
- 意图识别完成 → CHAT 直接回复；UNCERTAIN 进入 CLARIFYING；DOC/PPT 进入 FETCHING_SOURCES

---

### 2.5. CLARIFYING（追问中）

**入口条件**：
- 意图识别为 UNCERTAIN（最高置信度 < 0.7）

**行为**：
- 在飞书群内直接发送追问消息，不弹出卡片
- 例如："我有点不确定你想做什么，可以再具体描述一下吗？是想写文档，还是做 PPT，或者只是简单聊两句？"
- 等待用户补充信息

**退出条件**：
- 用户补充信息后 → 回到 ANALYZING 重新分析意图

---

### 3. FETCHING_SOURCES（获取三源中）

**入口条件**：
- 意图为 DOC 或 PPT

**行为**：
- 调用 fetch_feishu_chat_context 获取聊天记录（通过飞书 API，可为空白）
- 调用 fetch_bitable_data 获取表格数据（通过飞书 API，可为空白）
- 调用 search_knowledge_base 检索知识库（通过飞书文档 API，可为空白）
- 更新飞书卡片状态为"获取资料中"
- 三类信息来源均可为空白，不影响流程继续

**退出条件**：
- 三源获取完成（无论是否有内容）→ 进入 GENERATING

---

### 4. GENERATING（内容生成中）

**入口条件**：
- 从 FETCHING_SOURCES 进入

**行为**：
- DOC：调用 generate_document，流式输出 Markdown
- PPT：调用 generate_canvas，输出 Tldraw 元素
- 更新飞书卡片进度
- WebSocket 广播到工作台

**事件发布（DOC）**：

```json
{
  "type": "DOC_STREAM",
  "payload": {
    "chunk": "# 标题内容..."
  }
}
```

**事件发布（PPT）**：

```json
{
  "type": "CANVAS_UPDATE",
  "payload": {
    "upsert": [...],
    "delete": []
  }
}
```

**退出条件**：
- 内容生成完成 → 进入 SYNCING

---

### 5. SYNCING（同步与回流中）

**入口条件**：
- 从 GENERATING 进入

**行为**：
- 保存结果到 PostgreSQL
- 调用 return_to_knowledge_base 回流到 RAG 知识库
- 更新飞书卡片状态为"完成"

**退出条件**：
- 同步与回流完成 → 进入 COMPLETED

---

### 6. COMPLETED（已完成）

**入口条件**：
- 从 SYNCING 进入，或 CHAT 直接进入

**行为**：
- 更新飞书卡片为"已完成"
- 显示"确认保存"按钮
- 等待用户确认

**用户确认后**：
- 调用 archive_to_bitable 归档到飞书多维表格
- 飞书卡片状态更新为"已归档"
- 回到 IDLE

**事件发布**：

```json
{
  "type": "TASK_COMPLETED",
  "payload": {
    "result_url": "...",
    "bitable_id": "..."
  }
}
```

## 全局状态锁与权限管理

### 全局状态锁机制

- 当状态为 ANALYZING、FETCHING_SOURCES、GENERATING、SYNCING 时，工作台输入框锁定
- 锁定期间，只有创建者可以看到输入框，但无法提交（置灰）
- 其他群成员只读观摩，看不到输入框
- 进入 COMPLETED 状态后，锁释放，创建者可以继续输入

### 创建者主导模式

- 在飞书群首个 @Eko 触发任务的用户自动成为该会话的"创建者"
- 创建者：可编辑、可输入指令、可点击"确认保存"
- 其他群成员：只读观摩，只能查看进度
- 创建者权限通过飞书用户 ID 验证

---

## 异常处理

### 超时处理

- 任意状态超时 → 飞书卡片显示错误 → 回到 IDLE

### 用户中断

- 用户点击"取消" → 飞书卡片显示"已取消" → 回到 IDLE

### 错误处理

```json
{
  "type": "ERROR",
  "payload": {
    "code": "500",
    "message": "错误描述"
  }
}
```
