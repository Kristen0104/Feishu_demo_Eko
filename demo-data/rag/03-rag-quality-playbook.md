# NovaMind RAG 质量排查手册

更新时间：2026-05-03
适用对象：方案、交付、平台工程

## 1. 常见问题分类

### 1.1 召回不到

表现：

- 用户明明上传了文档，但回答说“没有相关信息”
- 搜索结果数量少于预期

优先检查：

1. 文档是否成功切块并写入向量库
2. metadata 是否写了错误的 source 或 user_id
3. 查询是否被过度改写

### 1.2 召回到了但回答不准

表现：

- 命中了文档，但最终答案引用错了段落
- 回答混入模型自身常识

优先检查：

1. prompt 是否明确要求“仅基于检索结果作答”
2. 返回上下文是否过长，导致关键信息被淹没
3. 是否缺少重排序

### 1.3 结果重复

表现：

- 多个 chunk 内容几乎相同
- 回答里多次重复同一句话

优先检查：

1. chunk overlap 是否过大
2. 同一文档是否重复导入
3. source + content_hash 去重是否失效

## 2. 推荐参数

- chunk size：400 到 600
- chunk overlap：60 到 100
- topK：4 到 8
- 先召回再重排：适用于高精度问答

## 3. 交付建议

- 先用 5 到 10 份高质量样本文档验证
- 不要一开始就导入大量噪声文档
- 每个知识库都准备 10 个标准测试问题
