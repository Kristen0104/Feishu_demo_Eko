# NovaMind 客户支持排障指南

更新时间：2026-05-05
适用对象：一线支持、解决方案工程师

## 1. 用户反馈“上传后无法提问”

优先排查：

1. 文档是否上传成功
2. 解析任务是否完成
3. rag_files 状态是否为 `indexed`
4. 前端是否拿到了最新知识库列表

处理建议：

- 如果解析失败，提示用户重新上传
- 如果仍失败，收集文件类型、大小、上传时间

## 2. 用户反馈“回答和文档不一致”

优先排查：

1. 是否命中了错误团队下的知识库
2. 是否存在历史重复文档
3. 问题是否过于模糊
4. 模型回答时是否混入常识补全

处理建议：

- 先让用户缩小问题范围
- 再检查召回片段是否正确
- 最后确认 prompt 是否要求基于资料回答

## 3. 用户反馈“团队成员看不到共享资料”

优先排查：

1. 用户是否加入正确团队
2. 前端登录态是否过期
3. 团队空间是否为空
4. 新上传资料是否仍在处理中

## 4. 用户反馈“系统变慢”

常见原因：

- 上传高峰期解析队列积压
- 推理模型选型过重
- 长会话上下文过大
- 检索返回内容过多

临时缓解：

- 切换到通用文本模型
- 降低 topK
- 缩短默认上下文长度

## 5. 支持升级标准

满足以下任一条件，应升级到工程团队：

- 同一客户 24 小时内重复出现 3 次以上
- 涉及数据错乱或跨团队可见
- 文档明明已索引，但始终无法召回
- 页面持续报错且前端刷新无效

## 6. 建议收集的信息

- 用户邮箱
- team_id
- session_id
- 文档名称
- 操作时间
- 问题截图
- 预期结果与实际结果
