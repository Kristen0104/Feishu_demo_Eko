# Eko 文档生成模块 - 联调指南

## 🚨 当前问题

**Python 3.14 beta + pydantic 兼容性问题**
- 错误: `TypeError: _eval_type() got an unexpected keyword argument 'prefer_fwd_module'`
- 原因: pydantic 2.13+ 与 Python 3.14 beta 不兼容

---

## ✅ 方案一: 使用测试接口（推荐）

无需启动完整服务器，直接使用 `/test/*` 接口模拟数据：

### 可用接口

| 接口 | 方法 | 说明 | 是否需要LLM |
|------|------|------|-----------|
| `/api/v1/document/test/generate` | POST | 模拟生成文档 | ❌ 不需要 |
| `/api/v1/document/test/save` | POST | 模拟保存文档 | ❌ 不需要 |

// 1. 测试生成文档

## ✅ 方案二: 降级依赖并启动服务

### 步骤 1: 降级 pydantic 版本

```bash
cd backend
py -m pip install "pydantic==2.7.4" "pydantic-settings==2.3.3" "fastapi==0.115.0"
```

### 步骤 2: 启动后端服务

```bash
cd backend

```

### 步骤 3: 访问 API 文档

打开浏览器访问: http://localhost:8000/docs

## 📋 完整接口文档

### 文档生成接口

#### 1. 生成文档（非流式）
```
POST /api/v1/document/generate
Content-Type: application/json

{
  "session_id": "string",
  "topic": "文档主题",
  "requirement": "具体需求描述",
  "chat_history": [
    {"role": "user", "content": "消息内容"}
  ],
  "knowledge_docs": [
    {"title": "文档标题", "content": "文档内容"}
  ],
  "bitable_records": [
    {"table_name": "表名", "fields": {"key": "value"}}
  ],
  "document_type": "general|plan|report|memo|meeting",
  "tone": "formal|casual|friendly|technical",
  "length": "short|medium|long"
}
```

响应:
```json
{
  "code": 0,
  "data": {
    "session_id": "string",
    "status": "completed",
    "content": "Markdown 文档内容"
  },
  "message": "success"
}
```

#### 2. 流式生成文档
```
POST /api/v1/document/generate/stream
Content-Type: application/json

// 请求体同上
// 响应: SSE 流式数据
```

#### 3. 保存并同步文档
```
POST /api/v1/document/save
Content-Type: application/json

{
  "session_id": "string",
  "title": "文档标题",
  "content": "Markdown 内容",
  "sync_to_feishu": true,
  "app_token": "可选",
  "table_id": "可选"
}
```

## 🔧 环境变量配置

确保 `.env` 文件包含:

```env
# LLM 配置
VOLCENGINE_API_KEY=your_api_key
VOLCENGINE_ENDPOINT=https://ark.cn-beijing.volces.com/api/v3
VOLCENGINE_MODEL=ep-your-endpoint-id

# 飞书配置（可选）
FEISHU_APP_ID=your_app_id
FEISHU_APP_SECRET=your_app_secret
```

## 💡 前端联调建议

1. **先使用测试接口**: `/test/generate` 和 `/test/save` 验证前端流程
2. **再切换完整接口**: 确认流程无误后，切换到真实接口
3. **处理 SSE 流式**: 流式接口需要特殊处理 `text/event-stream` 响应

## 📞 问题排查

| 问题 | 解决方案 |
|------|---------|
| 导入错误 | 降级 pydantic 到 2.7.4 |
| 连接失败 | 检查 Redis/PostgreSQL 连接 |
| LLM 报错 | 检查火山引擎 API Key |
| 飞书同步失败 | 检查飞书应用凭证 |
